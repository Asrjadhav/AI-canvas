🎨 AI Canvas – Generative AI Drawing & Image Creation Platform

Transform rough sketches and text prompts into AI-generated visuals using Generative AI

AI Canvas is an interactive web application that enables users to draw freely on a canvas or provide text prompts, and convert them into AI-generated images.

It bridges the gap between human creativity and artificial intelligence, making visual creation accessible even to non-designers.

✨ Features
🎨 Freehand drawing using Canvas API
🧠 AI-powered image generation (prompt-based)
✏️ Sketch → AI image transformation
⚡ Real-time interaction and rendering
💾 Download generated images
🔄 Smooth and responsive UI
🧠 How It Works
User draws on canvas OR enters a text prompt
Input is processed and sent to AI model via API
AI model generates refined image output
Result is displayed on UI in real-time
